# Python Text Editor

A simple **Text Editor / Notepad-style desktop application** built using Python and Tkinter.
This project was created to practice GUI programming, functions, menus, and file handling in Python.

## 📌 Project Overview

This Text Editor provides a simple interface for creating, opening, editing, and saving text files. It also includes basic text editing options such as Cut, Copy, Paste, and Select All.

The project helped me understand how Python can be used to create simple desktop GUI applications.

## ✨ Features

* 🆕 Create a new text file
* 📂 Open `.txt` files
* 💾 Save text files
* ✂️ Cut selected text
* 📋 Copy selected text
* 📌 Paste copied text
* 🔤 Select all text
* 🚪 Exit the application
* 📋 Simple File and Edit menus
